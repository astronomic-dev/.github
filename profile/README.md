# Astronomic

Production-ready Astro themes, components and plugins. Start at the launch pad, not the drawing board.

**[astronomic.dev](https://astronomic.dev)**

## Free and open source

| Project | What it is |
| --- | --- |
| [Astronomic UI](https://github.com/astronomic-dev/astronomic-ui) | Free, restylable Astro components. [Docs and examples](https://astronomic.dev/ui) |
| [Astronomic Search](https://github.com/astronomic-dev/search) | Typo-tolerant site search in a dialog for Astro. [Live demo](https://astronomic.dev/plugins/search) |
| [Vesper](https://github.com/astronomic-dev/vesper) | A free Astro theme for a personal blog and portfolio. [See the theme](https://astronomic.dev/themes/vesper) |
| [Astronomic Starter](https://github.com/astronomic-dev/astronomic-starter) | A free Astro + EmDash starter for a small product site. [See the starter](https://astronomic.dev/themes/starter) |
| [wp-esc](https://github.com/astronomic-dev/wp-esc) | Plan a move from WordPress to Astro or EmDash. [Read the guide](https://astronomic.dev/learn/wordpress) |

## Premium themes

Themes for agencies, studios, newsletters, real estate, trades and more. Every theme works with Markdown files or the EmDash CMS. [Browse the themes](https://astronomic.dev/themes)
